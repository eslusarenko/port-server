> Server-side application for the port project.

## Install

```bash
go install github.com/eslusarenko/port-server@latest
```

Or download a pre-built binary from [Releases](https://github.com/eslusarenko/port-server/releases).

## Usage

```bash
port-server --help
```

## Build from source

```bash
cd server
make build
```
